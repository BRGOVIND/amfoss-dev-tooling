# amfoss-dev-tooling

This repo sets up modern dev tooling for the amFOSS website, including:

- ✅ ESLint v9 with `eslint.config.js`
- ✅ Prettier for consistent formatting
- ✅ Husky pre-commit hook
- ✅ lint-staged for fast, staged-only linting
- ✅ Import sorting with `simple-import-sort`

### Setup

```bash
npm install
npm run format
npm run lint
